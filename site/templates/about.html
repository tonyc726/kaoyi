买 coding 套餐之前，把官方标价放在一起看。

为什么做这个

各家档位名字对不上。网上对照又常把不同梯子压成「入门 / 主力」，再打一个性价比分。你很难分清：哪句是官方价，哪句是活动，哪句是作者打分。

考异把这三件事分开给你看：官方标价、社区里正在发生的事、以及编辑判断。判断不合成总分，也不替你排序该买哪家。

名字取自司马光的考异——同一件事，几处说法并列，并写明为什么取这一处。

能帮你什么

  1. 一眼看到各家官方在卖哪几档、现在标价多少。看不到就写「-」。
  2. 售罄、限量、首月优惠单独记，不改写目录价，避免把活动价当成常价。
  3. 每个数字带着核对日期和官方页链接。下单前回到官方页确认。

怎么看这张表

档位按官方名称写，不互相对齐。例如 Claude 是 Free、Pro、Max 5x、Max 20x。ChatGPT 会员和 API 预付是两回事，表里只列会员。

人民币和美元分开写。页脚汇率是阅读辅助，不是牌价。价格是快照，不是实时行情。
