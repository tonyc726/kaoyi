三层分开看

官方标价、社区事件、编辑维度是三层。限时折扣或传闻不改写目录价；编辑判断不合成一颗星，也不按雷达面积排序。

  1. 官方标价：只写能在官方页核对的数字。看不到就写「-」。每格会带上 SRC OFFICIAL · AS OF 这样的来源和日期。
  2. 社区事件：售罄、限量、首月优惠。示例条目必须标成 EXAMPLE。
  3. 编辑维度：八个轴，各用 1 到 5 的整数。第一期全部写「未评」。

档位用官方名称

每个平台的梯子不一样。对照表按官方 SKU 逐行列出，例如 Claude 的 Max 5x 与 Max 20x，而不是「入门 / 主力 / 高用量」。

OpenAI ChatGPT/Codex 是会员套餐，不和 OpenAI API 预付或按量写在同一行。

单位怎么列

人民币价和美元价分列。页脚里的汇率快照是 {{ cfg.usd_to_cny_rate }}，日期 {{ cfg.usd_to_cny_as_of }}。它不是牌价，更不是官方人民币价。约合数字只作阅读辅助，不写进官方标价格。
