买 coding 套餐之前，把官方标价、单位成本和综合分放在一起看。

为什么做这个

各家档位名字对不上。网上对照又常把不同梯子压成「入门 / 主力」，再打一颗黑盒星。你很难分清：哪句是官方价，哪句是活动，哪句是作者打分。

考异现在会给你综合分和单位成本排序，方便一眼抓住相对位置。官方标价、社区事件、分数仍是三层，视觉上分开：分数不改写目录价，活动价不进标价格，缺证据的轴保持未评。

名字取自司马光的考异——同一件事，几处说法并列，并写明为什么取这一处。

能帮你什么

  1. 一眼看到各家官方在卖哪几档、现在标价多少。看不到就写「-」。
  2. 在官方写出可核对数的用量单位里，比较刊例单位成本（例如 ¥ / 万积分）。
  3. 综合分用已评轴的算术平均，写成 3.8 / 5 加「已评 N/8」。已评不足 3 轴则写「暂无综合分」，不会拿 3 去填空。
  4. 售罄、限量、首月优惠单独记，不改写目录价。
  5. 每个数字带着核对日期和官方页链接。下单前回到官方页确认。

怎么看这张表

档位按官方名称写，不互相对齐。例如 Claude 是 Free、Pro、Max 5x、Max 20x。ChatGPT 会员和 API 预付是两回事，表里只列会员。

人民币和美元分开写。页脚汇率是阅读辅助，不是牌价。美元刊例换成人民币比单位成本时，会标「编辑换算」。

价格与分数是定时快照（约每 3 小时），不是实时行情。

可获得性、价格结构、用量经济、稳定性、支付与区域、计费透明度由官方快照和状态页在每次抓取时重算。能力覆盖、切换成本仍是手写，不编造。手写轴不得用猜测填满。

传闻怎样变成事件

社区里单帖只是传闻，不会改表上的价。48 小时内出现至少两个互不转载的公开来源，才升格成事件页上的一条。升格之前，那一行是灰色的「未确认」。
